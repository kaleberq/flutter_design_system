# Flutter Design System

Um design system completo para Flutter.

## 📦 Instalação

Adicione ao seu `pubspec.yaml`:

```yaml
dependencies:
  flutter_design_system:
    git:
      url: https://github.com/kaleberq/flutter_design_system.git
      ref: v0.0.1
```

## 🚀 Uso

### Importação

```dart
import 'package:flutter_design_system/flutter_design_system.dart';
```
